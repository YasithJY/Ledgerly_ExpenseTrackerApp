3. CORE FEATURES & LOGIC SPECIFICATIONS
--------------------------------------------------------------------------------
1. Real-Time Balance Calculation:
   - Balance = Sum(Income Amounts) - Sum(Expense Amounts)
2. BNPL (Buy Now, Pay Later) Batch Generation:
   - When a BNPL expense is submitted for N months:
     * Split Amount = Total Amount / N
     * Creates N separate transaction records in the database, each dated 1 month apart.
     * Appends "(Installment X/N)" to the memo note.
3. On-Device OCR Text Extraction:
   - Regex pattern parsing for currency values: `(?:Rs|RS|rs|\$)\.?\s*(\d+(?:\.\d+)?)`.
4. Offline Data Persistence:
   - Local database caching using SQLite / Room / LocalStorage.
